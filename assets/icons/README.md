# 应用和模式图标

沿用原有深色圆形底与绿色电源符号，使用透明背景及抗锯齿。

| 文件 | 资源 ID | 用途 |
| --- | --- | --- |
| `app.ico` | 1 | 程序文件、安装包、快捷方式；运行中的安静模式 |
| `balanced.ico` | 2 | 运行中的均衡模式，蓝色 |
| `performance.ico` | 3 | 运行中的性能模式，红色 |
| `unknown.ico` | 4 | 正在读取或读取失败，灰色 |

每个 ICO 包含 16、20、24、32、40、48、64、96、128 和 256 像素的 PNG 帧，支持不同 Windows 缩放比例。`build.rs` 必须嵌入全部资源；第一个资源是绿色静态应用图标。图标不需要作为外部文件随应用安装。

需要重建资源时运行 `python scripts/generate-icons.py`，只使用 Python 标准库。生成器仅在开发时运行。

任务栏、标题栏、托盘及设置、关于、声明、关闭弹窗的图标均使用实际模式读回。关于页的图标使用独立的大尺寸句柄。托盘缓存四个图标并共享原生句柄，模式不变时不替换图标；仅状态、语言变化或每五秒注册检查时更新提示。窗口只在模式或 DPI 变化时加载替换图标，并在销毁时释放所有句柄。

资源及颜色检查：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-mode-icons.ps1`。测试模拟四种状态，不调用硬件接口、不改变系统主题或用户偏好、不干扰已运行应用；报告保存在 `logs/mode-icons/`。

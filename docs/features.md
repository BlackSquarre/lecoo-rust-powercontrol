# 登录启动、托盘与风扇控制

本文适用于 v0.0.3。使用紧凑 Windows 原生界面，支持系统深浅色主题、多语言切换和关于窗口。当前源码提供简体中文、英文、繁体中文、日语、韩语、西班牙语、法语及德语；详见[多语言说明](localization.md)。

## 登录启动与安装

发布同时提供 ZIP 便携版与 Inno Setup 安装版。安装版包含程序、硬件工具、快捷方式和卸载程序；不安装传感器驱动。原生 C 运行库静态链接，无需额外安装 .NET 或 VC++ 运行库。访问兼容的来酷 WMI 仍需要管理员权限。

在型号右侧齿轮的设置窗口勾选“登录后启动（进入托盘）”，默认关闭。状态直接查询 Windows 计划任务，任务名称为 `LecooRustPowerControl-<当前用户 SID>`。重复启用更新同一任务，关闭后删除并确认。执行文件移动后，重新启用可修复路径。安装版卸载时只清理指向本安装路径的应用启动任务。

任务使用当前用户的 InteractiveToken、HighestAvailable 和登录触发器，不保存密码，以 `--minimized` 启动。安装完成不会自动启用登录启动。真实下一次登录触发需在正常登录时确认。

## 托盘与窗口

托盘右键提供安静、均衡、性能、打开、最小化与退出。模式切换使用生产 WMI 方法并读回当前模式。双击打开；第二次启动会唤醒已有窗口。关闭时可选择进入托盘或退出并记住选择；设置中可以重置。偏好保存在 `%LOCALAPPDATA%\LecooRustPowerControl\preferences.txt`。

隐藏时销毁界面控件，保留控制窗口、托盘及轮询；风扇心跳持续运行。托盘注册失败不会隐藏窗口。

## 温度与风扇

温度通过 `root\WMI` 的 `MSAcpi_ThermalZoneTemperature` 读取 `ACPI\ThermalZone\TZ01_0`，按 `raw / 10 - 273.15` 换算摄氏。界面标注“ACPI 热区温度”，不称为 CPU Package 温度。缺少实例、访问失败或异常值显示不可用。本机已观察到 raw=3112（38.05°C），尚未验证负载变化及与 CPU 温度的对应关系。

功率显示与全部 WinRing0 访问已经移除。应用不包含、安装、启动或卸载该驱动；机器上官方软件安装的驱动不会被本应用改动。

风扇写入限定已验证的 Ryzen 7 8745H、指定 Lecoo WMI 实例及单风扇硬件。保留自动（固件编码 101）和最大（100）；低于最大风量的手动目标及滑条禁用。未验证的热区温度不能代替原有 CPU 过热保护。

`GetFanControl` 返回实测 RPM，固件不提供占空比或控制模式读回。最大风量会话由独立进程守护：心跳超过 3 秒、RPM 失效、正常退出或管道关闭时请求恢复自动并读回 RPM。自动恢复最多尝试三次，失败后请求最大风量并报告失败；恢复请求不能宣称为精确控制模式验证。

历史实验见[传感器调查](reference/wmi/native-sensor-research.md)；当前验证方法见[测试说明](testing.md)。

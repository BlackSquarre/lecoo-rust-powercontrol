## What's New

- Compact native Windows interface with system themes, Chinese/English switching and About.
- Temperature now comes from Windows ACPI thermal-zone WMI and is labelled accordingly.
- Removed package-power display and all WinRing0 access. No sensor driver is bundled or installed.
- Windows x64 releases now include a portable ZIP and an Inno Setup installer.

Auto and Maximum fan control remain available. Reduced manual fan targets are disabled until the thermal sensor is validated for CPU protection. Sign-in startup can be enabled in Settings.

---

## 更新内容

- 使用紧凑的 Windows 原生界面，支持系统主题、中英文切换和关于窗口。
- 温度改用 Windows ACPI 热区 WMI，界面同步标注温度来源。
- 移除封装功率显示和全部 WinRing0 调用，不附带或安装传感器驱动。
- Windows x64 同时提供 ZIP 便携版和 Inno Setup 安装版。

保留自动和最大风量；热区传感器完成 CPU 保护验证前，暂不开放降低风量的手动目标。登录启动可在设置中启用。

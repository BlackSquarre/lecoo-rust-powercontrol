Lecoo Rust PowerControl 0.0.2 adds login startup, notification-area controls, and guarded fan requests on the locally verified Lecoo MINI PRO with Ryzen 7 8745H.

### 新增功能

- **登录启动**：可选的当前用户管理员计划任务，默认关闭；支持实际状态查询、重复启用与删除，启动后进入托盘，不保存密码。
- **系统托盘**：专属电源图标；右键切换安静、均衡、性能，状态来自硬件读回；打开窗口、最小化到托盘和退出。单实例唤醒已有窗口，关闭到托盘行为可设置。
- **风扇控制**：自动、最大和 35–100% 手动目标；独立守护进程在 85°C、采样失效、主线程心跳超时或父管道关闭时尝试恢复自动。正常退出也恢复自动，恢复失败时尝试最大风量并报告错误。
- **原生温度**：独立 Rust 用户态代码直接读取已加载 WinRing0 的 AMD SMN CPU Package 温度，不使用官方界面的显示缩放。

### 下载与运行

下载 `lecoo-rust-powercontrol-v0.0.2-windows-x64.zip`，解压后运行 `lecoo-control-center.exe`。Windows 会请求管理员权限。压缩包包含图形应用、共用生产硬件库的 `hardware_test.exe` 和 `SHA256SUMS.txt`，另提供 ZIP 的 `.sha256` 校验文件。不附带或安装内核驱动。

### 验证与限制

- 10 项单元测试通过；本机已验证三种电源模式及读回、登录任务创建/运行/删除、托盘注册、窗口关闭到托盘、重复启动唤醒、隐藏窗口期间心跳、退出恢复。
- 短时 35/50/100% 请求影响实测 RPM；已验证非法值拒绝、心跳超时和父管道 EOF 后自动恢复请求与转速读回。
- **固件没有实际占空比或自动/手动模式读回接口**，RPM 不是占空比证明；界面区分本会话请求目标与实测转速。
- 手动风扇目前仅开放已验证的 8745H、指定 Lecoo WMI 实例、单风扇路径。原生温度和手动控制需要已加载且可访问的 WinRing0 1.2.0.5；驱动或温度不可用时拒绝手动控制。
- 真实登录触发未通过注销验证；过温及通信故障保护使用故障注入测试。软件不保证同时杀死全部进程、断电、固件失联时能够清理；短时验证不构成所有负载下的长期安全认证。
- UI 重设计及新动画未包含在此版本。现有官方应用可能覆盖风扇请求，请避免同时手动调速。

使用详情见 [功能说明](https://github.com/BlackSquarre/lecoo-rust-powercontrol/blob/v0.0.2/docs/features.md)；验证流程见 [测试文档](https://github.com/BlackSquarre/lecoo-rust-powercontrol/blob/v0.0.2/docs/testing.md)。

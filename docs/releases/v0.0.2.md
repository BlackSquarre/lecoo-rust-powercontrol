## What's New

Lecoo Rust PowerControl 0.0.2 adds Windows sign-in startup, tray shortcuts, and fan-speed controls.

## Improvements

- Optional sign-in startup launches the app into the tray with hardware access available.
- Tray shortcuts switch Quiet, Balanced, and Performance profiles and open or exit the app.
- Auto, Maximum, and 35–100% manual fan targets include temperature monitoring and automatic recovery when the app exits or stops responding.
- CPU temperature uses native readings without the official app's display scaling.
- Launching the app again opens the existing window. Closing to the tray is configurable.

## Bug Fixes

- Unavailable CPU temperature is displayed clearly instead of showing 0°C.
- Fan-speed readings decode the firmware's RPM field correctly.
- Hardware status polling no longer repeats on every gauge animation frame.

## 新功能

Lecoo Rust PowerControl 0.0.2 新增 Windows 登录启动、托盘快捷操作和风扇调速。

## 优化

- 可选的登录启动会将应用打开到托盘，并保留硬件访问权限。
- 托盘快捷菜单支持安静、均衡、性能模式，以及打开窗口和退出应用。
- 自动、最大和 35–100% 手动风扇目标配合温度监控，在应用退出或失去响应时尝试恢复自动控制。
- CPU 温度采用原生读数，不沿用官方程序的显示缩放。
- 再次启动会打开已有窗口，关闭窗口是否缩到托盘可自行设置。

## Bug 修复

- 温度无法读取时明确显示不可用，不再显示为 0°C。
- 正确解析固件返回的风扇 RPM 字段。
- 仪表动画不再导致每帧重复查询硬件状态。

## Downloads / 下载

- 提供 Windows x64 压缩包，解压后以管理员权限运行。
- 使用 ZIP 对应的 `.sha256` 文件及包内 `SHA256SUMS.txt` 校验下载文件。
- 手动风扇目前适用于已验证的 8745H 单风扇设备，并需要已加载的 WinRing0。界面显示请求目标与实测 RPM，固件不支持实际占空比读回。使用条件见[功能说明](https://github.com/BlackSquarre/lecoo-rust-powercontrol/blob/v0.0.2/docs/features.md)。

# Release Notes

## Eight interface languages

The app is available in Simplified Chinese, English, Traditional Chinese, Japanese, Korean, Spanish, French and German.

## Improvements

- Improved the Settings and About pages.
- Power-mode icons now reflect the current mode.
- Optimized background refresh, significantly reducing resource usage.
- Improved the reliability of sign-in startup, post-install launch and fan-control recovery.
- Includes a portable ZIP and Windows installer, with SHA-256 checksums.

Manual fan settings below Maximum remain unavailable pending thermal-safety validation.

# Release Notes / 发布说明

## Eight interface languages

The interface now supports 简体中文, English, 繁體中文, 日本語, 한국어, Español, Français and Deutsch. System default follows a supported Windows display language; explicit choices update the dashboard, Settings, dialogs, errors and tray immediately and persist across restarts. Chinese uses the script tags zh-Hans and zh-Hant, while existing zh-CN and zh-TW preferences remain readable.

## Other changes

- Added DPI-aware power-mode icons for the title bar, taskbar, tray and owned windows; refined the compact Settings layout and About page.
- Reduced idle timers from 250 ms to 1 second in the main window and 5 seconds in the tray. Temperature and fan readings update only while the dashboard is visible; memory updates every 2 seconds and system-drive capacity every 30 seconds.
- Replaced periodic theme polling and repeated PowerShell startup checks with Windows notifications and on-demand Task Scheduler COM queries. Memory and disk use native Windows APIs; unchanged readings reuse existing UI resources.
- The fan worker waits for commands or protection deadlines instead of polling every 100 ms. Recovery checks, RPM readback, asynchronous shutdown and fail-safe recovery remain in place.
- Added Windows CI and expanded release checks. This release passed all-target tests, release builds, installer installation, file-integrity and uninstall checks. ZIP and installer packages include SHA-256 files.

Timer-frequency reductions are not CPU or system-power measurements. ACPI temperature is not a verified CPU package reading, so manual fan targets below maximum remain disabled.

See [localization details](../localization.md) and [resource measurements and caveats](../resource-optimization.md).

## 八种界面语言

本版支持简体中文、English（英语）、繁體中文、日本語（日语）、한국어（韩语）、Español（西班牙语）、Français（法语）和 Deutsch（德语）。跟随系统会匹配受支持的 Windows 显示语言；手动选择会立即更新主界面、设置、对话框、错误提示和托盘，并在重启后保留。中文采用文字系统标签 zh-Hans、zh-Hant，旧版 zh-CN、zh-TW 偏好仍可读取。

## 其他更新

- 新增适配 DPI 的电源模式图标，覆盖标题栏、任务栏、托盘及所属窗口；调整紧凑设置页和关于页。
- 主窗口空闲定时器由 250 毫秒改为 1 秒，托盘由 250 毫秒改为 5 秒。仅在主界面可见时更新温度和风扇转速；内存每 2 秒更新，系统盘容量每 30 秒查询。
- 系统主题改用 Windows 通知；登录启动状态按需通过任务计划程序 COM 查询。内存和磁盘改用 Windows 原生接口，界面复用未变化的数据和资源。
- 风扇守护进程改为等待命令或保护期限，不再每 100 毫秒轮询；保留恢复检查、RPM 读回、异步退出和故障恢复。
- 新增 Windows CI 并扩展发布检查。本版通过全部目标测试、发布构建、安装、文件完整性和卸载检查。ZIP 与安装包均附 SHA-256 文件。

定时器频率变化不等于 CPU 或整机功耗测量。ACPI 温度尚未验证为 CPU 封装温度，因此低于最大风量的手动目标仍禁用。

详见[多语言说明](../localization.md)和[资源测量及限制](../resource-optimization.md)。

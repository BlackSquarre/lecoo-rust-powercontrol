# What's New

- Chinese language identifiers now describe the writing system: zh-Hans for Simplified Chinese and zh-Hant for Traditional Chinese. Existing zh-CN and zh-TW saved preferences remain readable.
- Reduced idle polling and unnecessary hardware and system queries. The GUI samples visible data on demand, uses native Windows memory and disk metrics, and responds to messages without waiting for long tray timers.
- Improved fan worker shutdown and recovery handling, WMI object reuse, startup-state queries, and native window resource reuse.
- Added isolated resource-usage documentation and measurement tooling.

The resource measurements use simulated hardware and do not establish real-system power savings or validate lower manual fan targets. Manual targets below maximum remain unavailable pending thermal-protection validation.

See [resource optimization details](../resource-optimization.md) and [localization notes](../localization.md).

## 更新内容

- 中文语言标识改用文字系统标签：zh-Hans 表示简体中文，zh-Hant 表示繁体中文。仍可读取旧版保存的 zh-CN 和 zh-TW 偏好。
- 减少空闲轮询及不必要的硬件、系统查询；界面数据按需采样，内存和磁盘指标改用 Windows 原生接口，托盘空闲时也能由消息及时唤醒。
- 改进风扇守护进程退出和恢复流程、WMI 对象复用、登录启动状态查询及原生窗口资源复用。
- 新增独立的资源占用说明和测量工具。

资源测量使用模拟硬件，不能据此证明真实系统功耗下降，也未验证较低的手动风量目标。CPU 热保护验证完成前，低于最大风量的手动目标仍不可用。

详见[资源优化说明](../resource-optimization.md)和[多语言说明](../localization.md)。
